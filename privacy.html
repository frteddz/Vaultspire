PRIVACY POLICY

Short version: this site collects nothing. Your server stores what a Minecraft plugin has to store.

1. This website

This is a static page hosted on GitHub Pages. There are no accounts, no cookies set by us, no analytics, and no contact forms. GitHub may log standard web server data on their side under their own policy.

2. The plugin

Vaultspire stores player UUIDs, usernames, vault counts, sealed gear, spire positions, and cooldowns in its own playerdata.yml and config.yml on your server. That data never leaves your machine and is never sent to the author or any third party.

3. Removal

Server owners can wipe a player by deleting the server plugin data files or resetting that player through the admin commands. Deleting the files removes everything the plugin knows.

4. Contact

Privacy questions go through the GitHub repo at github.com/frteddz/Vaultspire.
