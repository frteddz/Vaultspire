The loop

Vaults

Start with 18. Kills steal 1, any death seals 1. Zero means bankrupt and spectator.

Sealed slots

Locked slots plate over with vault metal. No dupes, no drops, no bypass. Clear or death reseals automatically.

Spires

Scattered lodestone spires. Pay the cost, name the bankrupt player, confirm. They return with 6 vaults.

Gear seals

Drop low and armor seals at random. Thresholds live in config under gear-seals.

Buyouts

Cheap spires

16 diamonds plus 6 echo shards. Hard guard, 3 waves.

Pricey spires

Totem plus netherite plus 16 echo shards. Easy guard, 1 wave.

Find them

/spiremap marks spires within 1000 blocks on real terrain. Each spire rests 90 minutes after a buyout.

Commands

/vaultYour open vaults and sealed gear.
/vaultguiFull menu. Status, spires, map, pack, help, credits, admin tools.
/vault helpEvery command, admin ones too if you are op.
/vault creditsAuthor, version, art notes.
/vault packTexture pack install help in game.
/spiremapMap to nearby spires. 20s cooldown.
/spirerandomScatter menu for ops. Amount plus per biome presets.
/spirerandom 5 1Scatter direct. 5 spires, 1 per split biome.
/vault set / addAdmin vault edits. Logged to console.
/vault spire addAdmin manual spire where you stand. Cheap or pricey.

Server install

1. Drop vaultspire-1.0.2.jar into plugins, restart.
2. As op run /spirerandom, hit Quick 5x1.
3. server.properties:
   resource-pack=https://frteddz.github.io/Vaultspire/vaultspire-pack.zip
   resource-pack-sha1=67ef259577522e0c8334b4d2afb6d06b01749a37
4. Restart, join, accept the pack.
