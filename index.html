VAULTSPIRE

1.0.1 by frteddz. Seal vaults, seal gear, fight over spires. Paper 1.21.11.

Download texture pack frteddz.github.io

The loop

Start with 18 vaults. Kills steal 1, any death seals 1. Zero means bankrupt.

Sealed slots lock with vault plating. Low vaults also seal armor and offhand at random.

Find a spire, pay the cost, name the bankrupt player. They return with 6 vaults.

Commands

/vault          your vaults
/vaultgui       full menu
/vault help     all commands
/vault credits  author and pack
/vault pack     pack install help
/spiremap       map to spires near you
/spirerandom    scatter menu (admin)

Server install

1. Drop vaultspire-1.0.1.jar into plugins, restart.
2. Run /spirerandom from the GUI as op.
3. server.properties:
   resource-pack=https://frteddz.github.io/Vaultspire/vaultspire-pack.zip
   resource-pack-sha1=50c7e072d77b3baad5b3c00a788680a679b2d6df
4. Restart, join, accept the pack.

Pack art made with the PixelLab API. Seal panes use model 9001.
