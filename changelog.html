CHANGELOG

Every release, newest first. Anything tagged dev testing shipped no public file.

1.0.3

STABLE
  • Resource pack fully retired. Vanilla textures everywhere, nothing to host.
  • /vault now opens the full menu. /vaultgui is gone.
  • Admin menu can revive any picked player, including yourself.
  • New /vault revive command for instant admin revives.
  • Manual spire placement with /vault spire add.
  • Buyouts ask for confirm with the exact cost before spending.
  • Player data lives in playerdata.yml with auto migration and batched saves.
  • Scatter runs across ticks, map views are reused, farm and cooldown caches prune.
